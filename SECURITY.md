# Security Policy

## Supported Versions

Only the latest released version of **runapi** receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub: [Report a vulnerability](https://github.com/Amanbig/runapi/security/advisories/new).

Include the affected version, a description, and reproduction steps. You can expect an acknowledgement within a few days, and we will coordinate a fix and disclosure with you.
